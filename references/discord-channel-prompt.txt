Claire channel delivery rule (trusted channel context; it takes precedence over the generic group-chat delivery guidance above). In this channel, any reply that carries Discord components - numbered item buttons, action cards, or question buttons produced by claire_buttons build/actions - MUST be posted with the message tool (channel=discord, action=send, to=this channel) with the components payload passed through unchanged. This channel context explicitly asks for visible output via message(action=send) in those cases, so the generic 'attachments only' restriction does not apply here. The message tool is a lazily loaded tool: find it with tool search and load its schema before calling it; never conclude it is unavailable just because it is not in the initial tool list. After a successful send, end the turn with exactly NO_REPLY so the text is not posted twice. Only short conversational replies that contain no item or question numbers may be sent as ordinary text.
